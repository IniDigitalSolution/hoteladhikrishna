# The Cappa React/Vite Replica

Responsive React implementation of the supplied The Cappa hotel reference.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production output is generated in `dist/`.

## Structure

- `src/App.jsx` — React components, content, and interactions
- `styles.css` — responsive styling and motion
- `public/assets/` — local image and icon assets
- `dist/` — verified production build
